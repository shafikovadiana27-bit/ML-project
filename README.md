# Machine Learning

Учебный проект по машинному обучению, включающий практические работы по анализу данных, подготовке признаков, классификации и регрессии.

В репозитории собраны Jupyter/Google Colab ноутбуки и Python-код, использованные в ходе курса.

## Что реализовано

В рамках проекта выполнены:

- первичный анализ и очистка данных;
- обработка пропусков и выбросов;
- преобразование числовых и категориальных признаков;
- One-Hot Encoding и Frequency Encoding;
- нормализация и стандартизация признаков;
- разделение данных на обучающую и тестовую выборки;
- обучение моделей классификации и регрессии;
- подбор гиперпараметров с помощью `GridSearchCV`;
- кросс-валидация;
- оценка качества моделей;
- построение confusion matrix и других визуализаций;
- сравнение различных преобразований целевой переменной.

## Использованные модели

### Классификация

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Decision Tree / Random Forest

Для многоклассовой классификации использовалось разбиение целевой переменной на ценовые категории. Для KNN, SVM и ансамблевых моделей исследовались различные наборы гиперпараметров.

### Регрессия

В практических заданиях рассматривались модели регрессии и влияние преобразований целевой переменной на качество прогноза.

Использовались, в частности:

- Linear Regression
- Decision Tree Regressor
- KNN Regressor
- Random Forest Regressor
- SVR

Для целевой переменной исследовались преобразования `log1p`, `sqrt` и Yeo–Johnson.

## Метрики

Для классификации:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

Для регрессии:

- MAE
- MAPE
- R²

## Работа с признаками

В проекте применялись:

- заполнение пропусков на основе групповых статистик;
- удаление дубликатов;
- фильтрация некорректных значений;
- One-Hot Encoding;
- Frequency Encoding;
- `StandardScaler`;
- `RobustScaler`;
- логарифмические и степенные преобразования;
- создание производных признаков, например возраста автомобиля;
- анализ распределений и корреляций.
